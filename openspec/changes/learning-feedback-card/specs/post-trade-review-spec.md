## Purpose

定义交易后复盘场景的事实采集边界、归因方式和**画像学习闭环**规则，确保复盘服务于长期方法论，而不是只做盈亏复述。本 spec 在 [原版 post-trade-review/spec.md](../specs/post-trade-review/spec.md) 基础上新增画像反馈层要求。

## Requirements

### Requirement: 交易后复盘必须记录结构化复盘输入
系统 SHALL 要求交易后复盘以结构化方式记录最小事实集。请求 MUST 至少覆盖实际采取的动作、触发该动作的原因和结果概述，并允许补充情绪状态、是否偏离原计划等上下文，以确保复盘围绕真实执行背景展开。

#### Scenario: 创建交易后复盘任务
- **WHEN** 用户提交合法的交易后复盘输入
- **THEN** 系统创建复盘分析任务并保留该次复盘所需的上下文字段

### Requirement: 复盘结论必须区分判断质量与执行质量
系统 SHALL 输出可读的归因结果，并同时覆盖判断质量、执行质量和运气因素。复盘结论 MUST 不能只依据盈亏结果做简单好坏判断，而应明确指出用户是否按计划执行、是否受情绪影响以及哪些因素属于不可控波动。

#### Scenario: 卖出后短期反弹
- **WHEN** 用户复盘一次卖出后短期反弹的交易
- **THEN** 系统仍按判断质量、执行质量与运气因素拆解结果，而不是仅用盈亏判断本次决策对错

### Requirement: 复盘结果必须沉淀改进动作
系统 SHALL 在复盘结果中给出下一次可执行的改进动作，并在需要时生成或更新后续复盘任务。改进动作 MUST 与识别出的行为偏差、计划偏离或证据缺失相对应，避免停留在抽象说教。

#### Scenario: 发现明显计划偏离
- **WHEN** 复盘结果识别出用户执行时明显偏离原计划
- **THEN** 系统返回针对性的改进动作，并为后续复盘或提醒保留结构化任务信息

### Requirement: 复盘提交后必须展示画像学习反馈（主动反馈模式）

系统 SHALL 在用户提交复盘后，通过 UI 层主动向用户展示本次复盘对画像的更新内容，**且行为标签更新必须经用户显式确认后才写入**。反馈 MUST 包含以下全部维度：

- **行为标签更新**：本次推断或确认的新增标签 + 来源说明
- **判断质量**：百分比主指标（0-100%）+ 趋势（近7天）+ 文字评价（三档：≥80%/60-80%/<60%）
- **判断构成**：四分类占比（主要来自判断 / 部分判断+运气 / 主要来自运气 / 难以区分）
- **情绪趋势**：最近30天情绪 sparkline + 均值 + 本次值
- **建议文案**：基于判断质量档位的可执行建议

#### Scenario: 复盘后展示反馈卡
- **WHEN** 用户完成 post-trade-review 并到达结果页
- **THEN** 系统延迟 800ms 后弹出画像学习反馈卡（轻阻塞 bottom sheet）
- **AND** 反馈卡包含上述全部五个维度
- **AND** 用户点击"确认"后行为标签才写入用户画像
- **AND** 用户点击"忽略"仅关闭弹窗，不写入标签

### Requirement: 复盘提交后必须异步写入判断质量历史

系统 SHALL 在复盘提交时，将判断质量选择（主要来自判断 / 部分判断+运气 / 主要来自运气 / 难以区分）以可聚合的形式存入历史记录，供后续计算判断质量百分比和趋势。

#### Scenario: 判断质量历史积累
- **WHEN** 用户完成第 N 次复盘并选择判断质量选项
- **THEN** 系统将本次选择以结构化形式存入判断质量历史
- **AND** 后续复盘展示的"判断质量%"基于历史均值计算
- **AND** 趋势（提升/下滑/稳定）基于近7天均值 vs 近30天均值对比

## Appendix: 判断质量计算规则

| 用户选择 | 分数 | 是否计入 |
|---------|------|---------|
| 主要来自判断 | 100 | 是 |
| 部分判断 + 部分运气 | 50 | 是 |
| 主要来自运气 | 0 | 是 |
| 难以区分 | - | **否** |

```
判断质量% = Σ(计入分数) / 计入次数 × 100%
趋势方向: delta ≥ 3% → 提升 | delta ≤ -3% → 下滑 | 其他 → 稳定
```

## Appendix: 行为标签推断规则

| 触发条件 | 推断标签 | 来源标注 |
|---------|---------|---------|
| intent ∈ {buy, add_position} AND trigger ∈ {连续上涨, 看到大涨} | 追涨倾向 | 连续上涨触发 + 本次复盘确认 |
| intent ∈ {sell, reduce_position} AND trigger ∈ {快速下跌, 恐慌性抛盘} | 恐慌卖出 | 快速下跌触发 + 本次复盘确认 |
| 用户在表单中手动勾选 | 对应标签 | 本次复盘确认 |
